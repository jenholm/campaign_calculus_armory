## Build Instructions

### Prerequisites
- TeX Live 2020+ (or MiKTeX)
- natbib package
- Standard LaTeX packages (amsmath, booktabs, graphicx, hyperref)

### Build PDF
```bash
cd paper
pdflatex manuscript.tex
bibtex manuscript
pdflatex manuscript.tex
pdflatex manuscript.tex
```

### Or use latexmk
```bash
cd paper
latexmk -pdf manuscript.tex
```
